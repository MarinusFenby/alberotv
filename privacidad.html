Política de privacidad

Esta política explica cómo trata la aplicación AlberoTV la información de sus usuarios.

Responsable

AlberoTV. Para cualquier consulta relacionada con privacidad puedes escribir a contacto@alberotv.com.

Datos personales

AlberoTV no exige crear una cuenta ni iniciar sesión. La aplicación no incorpora publicidad ni herramientas propias de seguimiento o analítica y no vende datos personales.

Ubicación

La función «Cerca de mí» puede solicitar, únicamente cuando el usuario la activa, permiso para acceder a una ubicación aproximada o precisa. Esa ubicación se usa de forma temporal en el dispositivo para calcular la distancia a los festejos cercanos. AlberoTV no la almacena en sus servidores ni la utiliza para identificar al usuario.

Cuando se busca una ciudad, el nombre escrito se consulta mediante el servicio de geocodificación de Open-Meteo para obtener sus coordenadas. No se envía a ese servicio la ubicación obtenida mediante el GPS del dispositivo.

Notificaciones, favoritos y descargas

Los avisos de eventos se programan como notificaciones locales del dispositivo. Los favoritos, preferencias, caché de programación y referencias a episodios descargados se guardan localmente para ofrecer las funciones solicitadas y el uso sin conexión. El usuario puede retirar permisos o eliminar estos datos desde los ajustes del dispositivo o desinstalando la aplicación.

Contenido y servicios externos

La aplicación descarga la programación desde alberotv.com y puede mostrar o reproducir imágenes, emisiones y pódcast alojados por terceros. Al abrir o reproducir esos recursos se establece una conexión directa con el proveedor correspondiente, sujeto a sus propias condiciones y políticas de privacidad.

Menores

AlberoTV es una aplicación informativa sobre programación y actualidad taurina. No está diseñada específicamente para menores ni recopila conscientemente datos personales de menores.

Seguridad y cambios

Se aplican medidas razonables para proteger el servicio y limitar el tratamiento de datos al mínimo necesario. Esta política podrá actualizarse si cambian las funciones de la aplicación o las obligaciones legales; la fecha de revisión aparecerá al comienzo de esta página.
